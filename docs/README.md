# Docs index

This folder contains design and implementation documents for the Image Cleansing Service.

- `image-cleansing-service.md` — Business Requirements Document (BRD). High-level goals, scope, success metrics.
- `image-cleansing-spec.md` — Technical Specification. API contracts, preprocessing pipeline, operational considerations.

Use the BRD for product discussions and the spec when implementing the PoC or production service.
